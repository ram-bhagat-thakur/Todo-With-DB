# Todo app with Database

This is a simple project in that i have uses MongoDB to store data permanently, in that i also have implemented functionality like adding new Task, Deleting task and updating task and also if an empty task is inserted then it will not going to store in Database and give an alert. Interface is so simple. 

For updating click on saved task input list write or change and also click on priority to change priority and then click on update it will be updated automatically for deleting click on delete button.
